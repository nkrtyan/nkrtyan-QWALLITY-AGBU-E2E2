# **Homework 31 — Qwallity API Testing**

Python scripts that test the **Qwallity API**

## **What It Does**

1. Register a new user
2. Login with that user
3. Add balance to the account
4. Check that the balance is correct

# **Files**

 **`data.py`** — test data (fake user information generated with Faker)
**`endpoints.py`** — API URLs
**`register_user.py`** — registers a new user
**`login.py`** — logs in and saves the token
**`add_balance.py`** — adds balance to the account
**`check_balance.py`** — checks that the balance was updated correctly
**`test.py`** — runs everything in order

## **How to Run**

Install the required libraries:

pip install requests Faker
```

Then run:

python test.py
